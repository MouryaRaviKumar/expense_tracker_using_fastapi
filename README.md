
Travel Expense Tracker API

1. Project Overview

During a trip, multiple friends spend money on food, travel, accommodation, shopping, 
tickets, and other activities. Usually, different people pay for different expenses, which 
makes it difficult to track how much each person has actually spent and how much they 
owe to others.

In this project, you will build a Travel Expense Tracker API that allows a group of friends 
to record, manage, and split their expenses during a trip.

The application will be developed as a backend REST API using Python, FastAPI, and 
MongoDB.

The main goal is to get practical experience with:

- FastAPI
- REST APIs
- Pydantic models
- MongoDB
- CRUD operations
- Query parameters
- Filtering and sorting
- Basic calculations
- MongoDB aggregation
- Input validation
- Error handling

---
2. Objective

Develop a backend system where users can:
- Create and manage trips
- Add friends to a trip
- Record expenses
- Specify who paid for an expense
- Specify who shared the expense
- Calculate individual shares
- View trip expenses
- Filter and search expenses
- Generate a trip-wise expense summary
- Understand who has paid more and who needs to pay others
